# Release Notes

Every time your squad ships something, add a short entry at the top. Newest
release goes first. Keep each entry to what a user would notice.

## Format

```
## v1.0 - YYYY-MM-DD
### Added
- Short, user-facing description of a new feature (link the ticket #).
### Fixed
- What was broken and now works.
### Changed
- Anything that behaves differently than before.
```

## v1.0 - 2026-11-08

### Added
- Added a flashcard quiz that shows users their scores and percentages.
- Added the ability to create and save new flashcards.
- Added category-based studying so users can focus on specific topics.
- Added a category breakdown showing how many flashcards are in each category.
- Added a deck summary to help users see information about their flashcards.
- Added an option to view the last flashcard in the deck.

### Fixed
- Fixed quiz scoring so users receive the correct score after completing a quiz.
- Fixed percentage calculations so quiz results display accurately.

### Changed
- Updated the main menu to make flashcard and quiz features easier to access.
